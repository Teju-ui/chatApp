# AI Chat App - Deployment Guide

Congratulations on finishing your AI Chat application! Since you have a Full-Stack application (a Node.js Backend and a React/Vite Frontend), you will need to deploy them to two separate hosting services. 

A common, free, and popular combination is:
- **Backend:** Hosted on **Render** (or Railway / Heroku)
- **Frontend:** Hosted on **Vercel** (or Netlify)

Follow these step-by-step instructions to get your app live on the internet!

---

## Part 1: Prepare the Code for Production

Before uploading your code, we need to make sure the Frontend and Backend know how to talk to each other over the internet instead of on your local machine (`localhost`).

### Step 1: Update Frontend URLs
In your `src/App.jsx`, you currently have a hard-coded localhost URL for your backend:
1. Open `c:\Users\tejut\chatApp\src\App.jsx`.
2. Find the Socket.io connection at the top: `const socket = io('http://localhost:5000');`
3. Find your Axios requests inside `handleAuth`: `axios.post('http://localhost:5000/api/auth/login'...)`
4. **Change them** to use an environment variable or your future live backend URL (e.g., `https://your-backend-name.onrender.com`).
   *Tip: In Vite, you can use `import.meta.env.VITE_BACKEND_URL` so you don't have to hard-code it forever!*

### Step 2: Push Your Code to GitHub
1. Create a GitHub account if you don't have one.
2. Create a new, empty repository on GitHub.
3. Open your terminal in `C:\Users\tejut\chatApp` and push your code:
   ```bash
   git init
   git add .
   git commit -m "Ready for production"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```

---

## Part 2: Deploying the Backend (Node.js & Socket.io)

We will use **Render.com** because it natively supports WebSockets (Socket.io) for free.

1. Go to [Render.com](https://render.com/) and create a free account linked to your GitHub.
2. Click **New +** and select **Web Service**.
3. Select your chat app repository from GitHub.
4. Configure the Web Service:
   - **Name:** Whatever you like (e.g., `my-ai-chat-backend`).
   - **Root Directory:** Type `backend` (since your server code is inside the backend folder).
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
5. **Add Environment Variables:**
   Scroll down to "Environment Variables" and add the keys from your `.env` file!
   - Key: `OPENAI_API_KEY` | Value: `gsk_yYwQ...`
6. Click **Create Web Service**. 
7. Wait 2-3 minutes for it to build. Once it says "Live", copy the URL (e.g., `https://my-ai-chat-backend.onrender.com`).

*(Note: Go back to Part 1 and paste this URL into your Frontend code, then push to GitHub again!)*

---

## Part 3: Deploying the Frontend (React & Vite)

We will use **Vercel** because it is incredibly fast and optimized for React/Vite.

1. Go to [Vercel.com](https://vercel.com/) and sign up with GitHub.
2. Click **Add New Project**.
3. Import your chat application repository from GitHub.
4. Configure the Project:
   - **Project Name:** (e.g., `ai-chat-app`)
   - **Root Directory:** If your React files (`package.json`, `index.html`) are in the root `chatApp` folder, leave this as `./`.
   - **Framework Preset:** Vercel should auto-detect **Vite**.
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. Click **Deploy**.
6. Wait 1-2 minutes. Vercel will give you a live URL (e.g., `https://ai-chat-app.vercel.app`).

---

## 🎉 You're Done!
Your app is now live. Anyone can visit your Vercel URL, create an account, chat with the AI, and talk to other connected users!

**Important Final Check:**
Make sure that your Backend CORS settings in `server.js` allow the frontend URL to connect:
```javascript
const io = new Server(server, {
  cors: { origin: 'https://your-vercel-frontend-url.vercel.app' }
});
```
